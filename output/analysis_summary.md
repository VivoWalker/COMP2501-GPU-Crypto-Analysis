# COMP2501 数据分析项目 — 分析过程与结果总结

## 项目概述

**主题**: NVIDIA GPU二级市场价格与加密货币关联性分析
**数据来源**: CoinGecko API + Tom's Hardware / PCMag / 3D Center / TechSpot
**分析时期**: 2020/09 – 2022/09
**工具**: Python (pandas, matplotlib, seaborn, scipy, statsmodels)

---

## 数据来源（100%真实，零推算）

| 数据 | 来源 | 条数 |
|------|------|------|
| 加密货币日线 | CoinGecko API | 1368 行 |
| 7款非LHR GPU eBay价格 | Tom's Hardware / PCMag / 3D Center | 141 行真实成交数据 |
| RTX 3060 Ti LHR eBay价格 | TechSpot / Tom's Hardware | 17 行真实发布数据 |
| RTX 3070 LHR eBay价格 | TechSpot / Tom's Hardware | 16 行真实发布数据 |
| RTX 3080 LHR eBay价格 | TechSpot / Tom's Hardware | 16 行真实发布数据 |
| GPU规格 (VRAM/算力/MSRP) | NVIDIA / TechPowerUp | 10 款型号 |

**最终数据集**: 190条观测，10款GPU，24个月。**零推算、零合成数据。**

---

## 分析迭代过程

### 第一轮：发现问题

| # | 问题 | 根因 |
|---|------|------|
| P1 | 交叉相关(CCF)出现虚假滞后（GPU看起来"领先"ETH） | ETH和GPU价格共享上升-下降趋势，原始价格水平产生虚假相关 |
| P2 | LHR价格全部从非LHR×固定折扣因子推算（三个型号discount完全相同=9.6%） | `03_fetch_gpu_prices.py` 用固定算法生成LHR价格，非真实数据 |
| P3 | 回归 `premium ~ VRAM` 系数为负 | MSRP是混淆变量：大VRAM卡MSRP高，溢价空间小 |
| P4 | LHR和hashrate在回归中共线 | 多重共线性（LHR设计上把算力减半） |

### 第二轮：改进方法

| 问题 | 解决方案 |
|------|---------|
| P1 | 改用**一阶差分**（月度变化量）做相关性，去除共同趋势 |
| P2 | 用户提供了TechSpot/Tom's Hardware发布的**真实LHR价格区间数据**，完全替换推算值 |
| P3 | 运行3个逐步回归模型（VRAM → VRAM+MSRP → VRAM+Tier），展示混淆过程 |
| P4 | 用$/MH挖矿成本指标替代价格比较，体现代价差异 |

### 第三轮：剔除剩余推算数据

- 用户指出RTX 3060 LHR价格仍为推算，提供了RTX 3060 Ti LHR真实价格
- 从数据集中**剔除RTX 3060 LHR**，替换为**RTX 3060 Ti LHR**（真实数据）
- 三个LHR对比组现在**100%真实数据**

## 9张分析图表及核心发现

### 1. `01_timeseries.png` — 时间序列总览
- 上板: GPU各层级中位价 vs ETH价格（双轴），标注LHR发布时间线
- 下板: 每款非LHR显卡独立价格走势
- **发现**: 所有GPU价格从2021年中峰值到2022年9月暴跌50-70%

### 2. `02_correlation.png` — ETH-GPU相关性
- 左板: ETH价格水平 vs GPU价格散点图 + 线性拟合
- 右板: 一阶差分相关性（去除共同趋势）；* = 显著(p<0.05)
- **发现**: ETH月度变化能预测部分GPU价格变化（RTX 3090: r=0.56, p<0.01）

### 3. `03_premium_drivers.png` — 溢价驱动因素
- 左板: VRAM vs 溢价散点图，标注混淆关系
- 右板: 各层级溢价箱线图 + ANOVA检验
- **3个回归模型**:
  - M1: `premium ~ VRAM` → 系数=-2.76（看似VRAM越多溢价越低）
  - M2: `premium ~ VRAM + MSRP` → 系数=+2.29（控制MSRP后反转）
  - M3: `premium ~ VRAM + Tier` → 系数=-12.05（层级才是真正决定因素）
- **核心发现**: **XX60溢价最高（107%），XX90溢价最低（52%）——低端卡被炒得最狠**

### 4. `04_lhr_comparison.png` — LHR挖矿限制效果（全真实数据）
- 三组同型号对比，均为真实发布数据:
  - **RTX 3060 Ti LHR**: 平均低16.3%，范围[1%-34%]
  - **RTX 3070 LHR**: 平均低16.4%，范围[0%-30%]
  - **RTX 3080 LHR**: 平均低19.5%，范围[4%-37%]
- **核心发现**:
  - **LHR价差不是固定的！** 随市场剧烈变化
  - 矿潮高峰时非LHR溢价最高达37%（RTX 3080，2022年1月）
  - 2022年中加密崩盘后，价差趋近于零（0-4%）
  - LHR挖矿成本贵40-50%（$/MH指标），NVIDIA成功阻止了矿工

### 5. `05_crash_analysis.png` — 崩盘幅度
- 10款显卡峰值→谷底价格瀑布图
- **发现**: 平均跌幅62.4%；RTX 3080最惨(-71.9%)；RTX 3070 Ti最轻(-55.4%)

### 6. `06_mining_economics.png` — 挖矿经济学
- 左板: 各层级$/MH时间序列
- 右板: 每款显卡$/MH（虚线=LHR，挖矿价值更差）
- **发现**: 2022年中所有层级$/MH趋同至$7-10，挖矿不再盈利

### 7. `07_btc_vs_eth.png` — BTC vs ETH影响力对比
- 左板: 简单相关系数
- 右板: 偏相关系数（控制对方后的净效应）
- **意外发现**: **BTC (r=0.391) 比 ETH (r=0.256) 与GPU价格相关性更强**
  - 偏相关: BTC仍保持r=0.322，ETH降至-0.104
  - 解释: BTC充当"加密市场情绪指标"，整体市场情绪驱动GPU需求

### 8. `08_volatility.png` — 价格波动率
- 上板: 各层级波动率时间序列
- 下板: 波动率箱线图 + 统计量
- **发现**: 波动最剧烈在2021年中（价格飙升期）；XX90波动幅度最大

### 9. `09_correlation_heatmap.png` — 变量相关性热力图
- 仅保留下三角，去除冗余变量
- **最强相关**: Hashrate与GPU价格 (r=0.76)
- **最弱相关**: ETH波动率与GPU价格 (r=0.09)

## 数据局限性

1. **LHR价格使用区间中位数**: 原始来源发布的是价格范围（如$1200-$1600），取中点作为点估计
2. **样本量有限**: 10款GPU、24个月
3. **渠道局限**: 仅eBay.com已售清单，不含其他二手平台
4. **加密货币来源**: CoinGecko成交量加权均价，可能与单一交易所有小幅差异（1-3%）
